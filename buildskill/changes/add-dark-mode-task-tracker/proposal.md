# Add Dark Mode Task Tracker

## Why

add dark mode task tracker

The goal is to convert the idea into a small, runnable first version with enough structure to extend safely.

## What Changes

- Focused interface for Dark Mode Task Tracker.
- Add user-created items from a form.
- Persist items in localStorage.
- Show live item counts.
- Toggle and persist dark mode.
- Mark items complete.

## Capabilities

### New Capabilities

- `app`: User-facing static web app generated from this change.

## Impact

- Output folder: `builds/add-dark-mode-task-tracker`
- Generated files: `index.html`, `styles.css`, `script.js`, `README.md`
- No external dependencies are required.
